# Конструктор резюме

Сайт, где можно собрать резюме. Можно загрузить фото и старое резюме, написать о себе — ИИ сам заполнит резюме и подскажет, какую работу искать в твоём городе.

## Что умеет

- 3 шаблона: Классика, Модерн, Минимал
- 5 цветов
- заголовки на русском, кыргызском и английском
- загрузка фото
- чтение старого резюме (PDF, Word, txt, картинка)
- кнопка «Улучшить текст с ИИ»
- подбор работы в КР: после сборки резюме открывается поиск вакансий на нескольких сайтах
- скачать резюме и распечатать в PDF
- всё сохраняется в браузере (localStorage)

## Файлы

- `public/index.html` — разметка
- `public/style.css` — стили сайта
- `public/resume.css` — стили самого резюме
- `public/app.js` — вся логика
- `server.js` — сервер (отдаёт сайт и ходит в Claude API)

## Как запустить

1. Нужен Node.js 18 или новее
2. Скопировать `.env.example` в `.env` и вставить свой ключ с console.anthropic.com
3. В терминале: `npm start`
4. Открыть http://localhost:3000

Без ключа сайт тоже работает, просто без ИИ.

## Обновление сайта

После изменений в `style.css`, `resume.css` или `app.js` увеличь номер `?v=` в `public/index.html` — иначе у посетителей может остаться старая версия из кэша.

## Где работает ИИ

- **Внутри Claude (claude.ai)** — ИИ работает через аккаунт Claude того, кто открыл страницу, ключ не нужен.
- **Со своим сервером** (`npm start` и ключ в `.env`) — ИИ работает для всех.
- **На GitHub Pages** сайт сам обращается к серверу на Render (`resume-builder-kg.onrender.com`), поэтому ИИ работает и там.

## Хостинг сервера на Render

1. Открыть https://render.com/deploy?repo=https://github.com/alizhajloobekov-cmd/resume-builder
2. Войти в Render и вставить ключ ИИ:
   - бесплатно — `GROQ_API_KEY` с https://console.groq.com/keys
   - или Claude (платно, качественнее) — `ANTHROPIC_API_KEY` с https://platform.claude.com/settings/keys
   Если есть оба ключа, используется Claude; выбрать вручную можно переменной `AI_PROVIDER` (`groq` или `anthropic`).
3. Нажать Apply — Render возьмёт настройки из `render.yaml`.

Защита ключа: сервер принимает запросы только с сайта на GitHub Pages и не больше 30 запросов к ИИ с одного IP в час (меняется в `RATE_LIMIT_PER_HOUR`). Бесплатный сервер засыпает после 15 минут без запросов, первый запуск после этого занимает до минуты.
